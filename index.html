Core Subsystems

Designed for long-run, stable farming without manual intervention.

Docked Window Engine

Roblox is embedded directly into the macro UI as a native child window. Input commands register cleanly without stealing desktop cursor focus or relying on external overlay windows.

Task Queue & Recovery

Build queues for Story, Raid, or Expedition stages. If a match is lost or stuck, the macro automatically returns to lobby and retries.

Macro Manager & Paths

Visual block builder for pre-start routines (starter unit placement, in-game hotkey toggles, and WASD walk path recording).

Discord Webhook OCR

Automatic screen OCR reads Yen, damage, clear time, and rewards off match end screens, posting summary cards to Discord.

Editable Asset Crops

All template images live in an open `Assets/` directory. Replace or crop missing button templates via Image Manager without recompiling.

Frequently Asked Questions

Everything you need to know about Cream's Macro for Anime Expeditions.

Is Cream's Macro safe to use?

Yes! Cream's Macro is 100% vision-based (OpenCV image recognition + screen capture). It does NOT inject code, modify Roblox memory, or hook game APIs.

Does it auto-farm Story, Raids, and Expeditions?

Yes. You can build complex queues combining Story stages, Raids, Expeditions, and Daily Challenge maps, with custom repeat counts and auto-recovery on defeat.

How do Discord Webhooks work?

Add your Discord webhook URL in Settings. The macro will automatically send match victory/defeat summary cards along with Yen earned, damage dealt, and screen crops.

What are the system requirements?

Windows 10/11 x64 (primary) or macOS (experimental beta). Tesseract OCR is optional for reading text statistics off match end screens.
