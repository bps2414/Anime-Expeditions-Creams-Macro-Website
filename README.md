# Cream's Macro — Official Website & Landing Page

Official landing page and website for **Cream's Macro | Anime Expeditions**, built using vanilla HTML5, CSS3, and JavaScript, designed to match the native UI design system of the Cream's Macro application.

## Features

- **Native App Design System**: Built with exact color tokens (`--bg-deep: #11131c`, `--bg-card: #171a26`, `--brand: #7c9dff`, etc.), Liquid Glass aurora effects, and Sora + Inter + JetBrains Mono fonts mirroring the macro's app interface.
- **GitHub API Integration**: Automatically fetches the latest release tag (`v0.0.1+`) and live total download counts.
- **YouTube Guide Integration**: Prominently highlights official tutorials by `@Cweamya`.
- **Live Theme Switcher**: Interactive header widget demonstrating the macro's color accent system.
- **Zero Dependencies**: Pure HTML, CSS, and JS — lightweight, fast, and 100% compatible with GitHub Pages, Vercel, or Netlify.

## Usage

Simply open `index.html` in any web browser or serve via any static file server:

```bash
npx serve .
```

## Deployment

Deploy directly to GitHub Pages, Vercel, or Netlify by setting the root directory to this repository.
